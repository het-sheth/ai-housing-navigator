# Disclosures and limits

## Authority and uncertainty

This is a one-case demonstration, not validated practitioner advice. Inputs are hypothetical assumptions. No current occupancy, lawful use, complete zoning compliance, variance requirement, permit exemption or approval probability is established. Assessment says vacant land while six completed PLI records describe dwelling work; neither overrides the other. A missing occupancy certificate alone does not prove illegality.

Mapped R1D-H means high-density single-unit detached residential, not the separate Hillside district. Approved is a zoning layer attribute, not approval of this project. Slope intersection does not establish overlap percentage, surveyed slope, disturbance or automatic review requirements. Flood, historic, undermining, contamination, title, structural condition and utility capacity remain unresolved. Financial feasibility is unassessed. No funding gap is calculated from permit value and advertised asking price.

The first slice uses conditional, narrowly interpreted rule checks. Section 921.03 was re-opened September 26, 2026 at https://ecode360.com/45478965 to confirm A.1 versus D.1. Full dependency, exception, amendment and effective-date review remains outstanding. Current code and City interpretation must govern any real project.

## Comparison value boundary

Repair versus expansion with all other evaluated inputs held constant currently changes an explanation but not the review status or next action. The UI and export report those separately. A disturbance/no-disturbance alternative changes a site-plan diligence request only. No tested comparison establishes an approval outcome, preferred acquisition or financial result. Comparison itself is not claimed as unique. TestFit-style building design and pro formas are outside this weekend scope.
